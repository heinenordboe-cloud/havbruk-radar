# Pinnet eksakt med vilje. Denne jobben skal kjøre uten tilsyn i to år,
# og en jobb som installerer "nyeste" hver mandag er en jobb som en
# tilfeldig mandag møter et endret API og blir rød uten at du gjorde noe.
#
# Oppgradering skjer når DU velger det: bump versjonen, kjør pytest, commit.
# Regenerer med: pip freeze | grep -iE "^(httpx|polars|pypdf|PyYAML)=="
#
# pyarrow er fjernet: polars leser og skriver parquet selv, og pyarrow
# ble aldri importert noe sted i koden.

httpx==0.28.1
polars==1.36.1
PyYAML==6.0.3

# Leser ekspertgruppens rapporter, som bare finnes som PDF. Kom inn
# 26.08.2026 — den var ad hoc-installert i .venv fra 25.08 og sto ikke
# her, som er nøyaktig det denne fila finnes for å hindre.
#
# Brukes for tekstuttrekk, ikke for skriving. `extraction_mode="layout"`
# er det som gjør tabellene i rapportene lesbare i det hele tatt: uten
# den kollapser kolonnene, og en rad med tomme celler kan ikke tilordnes
# metode. Se sources/ekspertgruppen.py.
pypdf==6.16.2
# Kreves av pypdf for AES-krypterte PDF-er. 2023-ekspertgrupperapporten
# er kryptert (tom eierpassord, kun rettighetsbegrensning), og uten denne
# kaster pypdf DependencyError før første side er lest. De sju andre
# årgangene er ukrypterte — dette er den ene kroppen som krever den, og
# den kan ikke leses uten.
cryptography==50.0.1

# Rendrer den publiserte nettsiden. Kom inn 16.09.2026 — og som pypdf i
# august var den ad hoc-installert i .venv før den sto her, som er
# nøyaktig det denne fila finnes for å hindre.
#
# Valgt framfor f-strenger og str.format av én grunn: AUTOESCAPING.
# Sidene bygges av registerdata vi ikke kontrollerer — et lokalitetsnavn
# eller et selskapsnavn er en streng fra en tredjepart, og den skal ikke
# kunne bli markup. `autoescape=True` gjør det til standarden i stedet
# for noe hver enkelt skriving må huske, som er samme form som at
# persondatafilteret ligger i lesedøra og ikke hos hver leser.
#
# Ingen Hugo, ingen Node, ingen JS-byggekjede: det ville vært et andre
# språk og en andre pakkebrønn i en jobb som skal stå uten tilsyn i to
# år. Målt før valget: 2000 sider à 200 tabellrader rendres på 0,04 s.
# Byggetid er ikke en begrensning her, og det er derfor enkelhet kan
# vinne.
Jinja2==3.1.6
