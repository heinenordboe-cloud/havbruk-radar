# Python 3.12 er prosjektets versjon

**Bestemt:** `.python-version` sier 3.12, som er det Actions kjører.
Lokalt kjører Heine 3.9.6 (Apples innebygde) inntil videre.

**Hvorfor:** Å ha versjonen skrevet ned er verdt noe selv når maskinen
ikke følger den ennå — da er avviket kjent i stedet for tilfeldig.
Avhengighetene er pinnet, og testene er grønne på begge versjoner i dag,
så sprekken koster ingenting akkurat nå.

**Prisen:** En syntaks- eller biblioteksforskjell mellom 3.9 og 3.12 vil
dukke opp i produksjon mandag morgen i stedet for på skjermen. CI fanger
det samme dag som pushen, ikke samme sekund som redigeringen.

**Ville snudd det:** Første gang noe er grønt lokalt og rødt i Actions,
eller motsatt. Da installeres 3.12 lokalt samme kveld.
