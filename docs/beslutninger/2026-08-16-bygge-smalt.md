# Bygge smalt og starte, framfor bygge ferdig

**Bestemt:** To kilder planlagt, én i drift. Ikke syv.

**Hvorfor:** Heine ville opprinnelig bygge alt før noe kjørte. Sju kilder
med hver sine format og feil er trolig to måneders arbeid, og i de to
månedene samles null data. Historikken er hele fortrinnet og kan ikke
rekonstrueres.

**Ville snudd det:** Ingenting. Dette er prinsippet prosjektet hviler på.
